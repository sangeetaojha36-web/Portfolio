# Sangeeta Ojha — AI / ML & Software Developer Portfolio

An architectural, editorial portfolio for **Sangeeta Ojha**, inspired by the design language and structure of **Zainab Kabira** (`zainabkabira.com`), crafted with **React 18, TypeScript, Vite, and Tailwind CSS**.

## Design System & Highlights

- **Aesthetic & Visual Tone**:
  - **Warm Paper & Obsidian Studio Themes**: Default warm architectural ecru paper (`#FAF7F2`) with an instant dark studio toggle.
  - **Editorial Typography**: Pairing **Instrument Serif** italic and display headlines with **Plus Jakarta Sans** and **JetBrains Mono**.
  - **Organic Ambient Light Vignette**: Canvas-driven fluid light diffusion that gently drifts in the background.
  - **Delicate Architectural Grid**: Subtle grid lines evoking blueprints and physical paper.
- **Floating Signature Pill Navigation**:
  - Centered floating glass pill menu: `Selected Works`, `Playground`, `The Person Behind`, `Experience`, `Academics`, `Contact`.
  - Live IST time capsule (`IST HH:MM:SS AM/PM`), Dark/Light mode switcher, and official PDF Resume drawer trigger.
  - Fully responsive with mobile drawer.
- **Selected Works (Deep Case Studies)**:
  - Museum-grade project articles featuring:
    1. **AI Interviewer**: Mock Interview & NLP Scoring Platform.
    2. **Serenity**: Mental Health & Wellness Platform with AI Companion Sera, interactive 3D games, and celestial star-gazing.
    3. **AI Skill Mentor**: IBM SkillsBuild × BharatCares capstone aligned with UN Sustainable Development Goals.
    4. **AI Career Path Recommendation System**: Personalized career roadmaps.
    5. **Food Express**: Real-time food delivery with live tracking and Firebase.
    6. **TaskVibe**: Minimalist offline-first task manager.
  - Category filter pills, detailed project modals, source code links, and live demos.
- **The Playground (Interactive Vignettes)**:
  - **Study 01 • NLP Feature Scoring**: Interactive response evaluator analyzing keyword depth, vocabulary sophistication, and cosine relevancy for target roles (AI/ML, Software Developer, HR).
  - **Study 02 • Serenity Star-Gazer**: Interactive celestial canvas where visitors can hover and drag to connect star constellations (Polaris, Dubhe, Vega, Sirius).
  - **Study 03 • 3D Card Physics & Confetti**: Tactile 3D perspective flip card demonstrating Serenity's gamified daily wellness habits.
- **The Person Behind (the Pixels)**:
  - Personal narrative essay detailing Sangeeta's journey from Bhilai, Chhattisgarh to CSIT Durg.
  - Reflections on how tactile crafting (crochet) informs clean, structured code.
  - Leadership as Vice President of The SEnA (2026–27) and UN SDG commitments.
- **Experience & Academics**:
  - IBM SkillsBuild × BharatCares with AICTE (Machine Learning & Applied AI Intern).
  - B.Tech CSE, CSIT Durg (2023–27, CGPA 7.8/10), Class XII (65.5%), Class X (86%).
  - Technical toolkit mapped by proficiency (Languages, AI/ML, Web, Database & Core CS).
- **Official PDF Resume**:
  - Directly loads `Sangeeta_Ojha_Resume24_e8a52240.pdf` with an in-modal PDF viewer, open in new tab, and 1-click download.
